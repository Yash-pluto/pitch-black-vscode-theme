Pitch Black uses a unified `#101010` background to reduce eye strain, paired with a carefully balanced syntax palette that keeps code easy to scan without visual clutter.

## Features

- **Unified interface** - a consistent `#101010` background across the editor, terminal, activity bar, and sidebars.
- **Subtle UI accents** - active tabs and elements highlighted in soft Lilac (`#C699FF`), while inactive elements blend into the background.
- **Clean syntax highlighting:**

| Color | Hex | Used for |
|---|---|---|
| White | `#FFFFFF` | Variables, plain text |
| Lilac | `#C699FF` | Functions, classes, HTML tags, JSON keys |
| Cyan | `#99FFE4` | Strings, inherited classes, symbols |
| Slate | `#A0A0A0` | Keywords, operators, punctuation |
| Magenta | `#E580FF` | Errors, invalid syntax, deleted code |
| Muted Gray | `#8B8B8B` | Comments |

## Installation

**Via Marketplace**
1. Open the Extensions sidebar (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Search for **Pitch Black**.
3. Click **Install**.
4. Open the Command Palette (`Ctrl+K Ctrl+T` / `Cmd+K Cmd+T`) and select **Pitch Black**.

**Manual Installation**
1. Download the latest `.vsix` from the repository's Releases page.
2. Drag and drop the file into the Extensions sidebar.
3. Select **Pitch Black** in your Color Theme settings.
